  1. 1. Потенциал электростатического поля точечного заряда
    $$\varphi = \frac{1}{4\pi\varepsilon_0} \frac{q}{r}$$
  2. 2. Напряженность поля бесконечной плоскости
    $$E = \frac{\sigma}{2\varepsilon_0}$$
  3. 3. Параллельное соединение конденсаторов
    $$C_{\text{общ}} = \sum C_i = C_1 + C_2 + \dots + C_n$$
  4. 4. Связь напряженности и индукции электростатического поля в веществе
    $$\vec{D} = \varepsilon_0 \vec{E} + \vec{P} = \varepsilon\varepsilon_0 \vec{E}$$
  5. 5. Параллельное соединение резисторов
    $$\frac{1}{R_{\text{общ}}} = \sum \frac{1}{R_i} = \frac{1}{R_1} + \frac{1}{R_2} + \dots + \frac{1}{R_n}$$
  6. 6. Закон Джоуля-Ленца
    $$Q = I^2 R t = U I t = \frac{U^2}{R} t$$
  7. 7. Второе правило Кирхгофа
    $$\sum_k I_k R_k = \sum_k \varepsilon_k$$
  8. 8. Индукция магнитного поля бесконечного прямого провода
    $$B = \frac{\mu_0 I}{2\pi r}$$
  9. 9. Сила взаимодействия двух параллельных токов
    $$F = \frac{\mu_0 I_1 I_2}{2\pi d} l$$
  10. 10. Сила Лоренца
    $$\vec{F} = q (\vec{E} + [\vec{v} \times \vec{B}])$$
  11. 11. Связь напряженности и индукции магнитного поля в веществе
    $$\vec{B} = \mu_0 (\vec{H} + \vec{J}) = \mu\mu_0 \vec{H}$$
  12. 12. Закон Фарадея
    $$\varepsilon_i = -\frac{d\Phi}{dt}$$
  13. 13. Энергия катушки индуктивности
    $$W = \frac{L I^2}{2}$$
  14. 14. Энергия магнитного поля
    $$\text{Полная: } W = \frac{L I^2}{2} \quad \text{Плотность: } w = \frac{B^2}{2\mu\mu_0} = \frac{\mu\mu_0 H^2}{2}$$
  15. 15. Циклическая частота колебательного контура
    $$\omega = \frac{1}{\sqrt{LC}}$$
