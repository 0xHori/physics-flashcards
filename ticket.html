Справочник всех формул по физике

№ Название величины / закона Формула
БЛОК 1: Электростатика. База
1 Закон Кулона $$F = \frac{1}{4\pi\varepsilon_0} \frac{|q_1| |q_2|}{r^2}$$
2 Напряженность поля точечного заряда $$\vec{E} = \frac{1}{4\pi\varepsilon_0} \frac{q}{r^3} \vec{r}$$
3 Потенциал поля точечного заряда $$\varphi = \frac{1}{4\pi\varepsilon_0} \frac{q}{r}$$
4 Связь напряженности и потенциала $$\vec{E} = -\text{grad } \varphi = -\nabla \varphi$$
5 Интегральная связь поля и потенциала $$\varphi_1 - \varphi_2 = \int_{1}^{2} \vec{E} \cdot d\vec{l}$$
6 Теорема Гаусса в интегральной форме $$\oint_S \vec{E} \cdot d\vec{S} = \frac{Q_{\text{внутр}}}{\varepsilon_0}$$
7 Дипольный момент $$\vec{p} = q \vec{l}$$
8 Напряженность поля диполя $$\text{На оси: } \vec{E} = \frac{1}{4\pi\varepsilon_0} \frac{2\vec{p}}{r^3} \quad \text{На перпендикуляре: } \vec{E} = -\frac{1}{4\pi\varepsilon_0} \frac{\vec{p}}{r^3}$$
9 Потенциал поля диполя $$\varphi = \frac{1}{4\pi\varepsilon_0} \frac{p \cos\theta}{r^2}$$
10 Момент сил, действующих на диполь $$\vec{M} = \vec{p} \times \vec{E}$$
11 Потенциальная энергия диполя $$W = -\vec{p} \cdot \vec{E} = -pE \cos\alpha$$
БЛОК 2: Электростатика. Проводники и поля
12 Напряженность поля бесконечной плоскости $$E = \frac{\sigma}{2\varepsilon_0}$$
13 Потенциал поля бесконечной плоскости $$\varphi = -\frac{\sigma}{2\varepsilon_0} x + C$$
14 Напряженность поля заряженной нити $$E = \frac{\tau}{2\pi\varepsilon_0 r}$$
15 Потенциал поля заряженной нити $$\varphi = -\frac{\tau}{2\pi\varepsilon_0} \ln r + C$$
16 Напряженность поля на оси заряженного кольца $$E = \frac{1}{4\pi\varepsilon_0} \frac{q z}{(R^2 + z^2)^{3/2}}$$
17 Потенциал поля на оси заряженного кольца $$\varphi = \frac{1}{4\pi\varepsilon_0} \frac{q}{\sqrt{R^2 + z^2}}$$
18 Напряженность поля проводящей сферы. Внутри сферы $$E = 0 \quad (r < R)$$
19 Потенциал поля проводящей сферы. Внутри сферы $$\varphi = \frac{1}{4\pi\varepsilon_0} \frac{q}{R} = \text{const} \quad (r \le R)$$
20 Напряженность поля проводящей сферы. Снаружи сферы $$E = \frac{1}{4\pi\varepsilon_0} \frac{q}{r^2} \quad (r > R)$$
21 Потенциал поля проводящей сферы. Снаружи сферы $$\varphi = \frac{1}{4\pi\varepsilon_0} \frac{q}{r} \quad (r > R)$$
22 Напряженность поля равномерно заряженного шара. Внутри шара $$E = \frac{1}{4\pi\varepsilon_0} \frac{q r}{R^3} \quad (r < R)$$
23 Потенциал поля равномерно заряженного шара. Внутри шара $$\varphi = \frac{1}{4\pi\varepsilon_0} \frac{q (3R^2 - r^2)}{2R^3} \quad (r \le R)$$
БЛОК 3: Электроемкость и Конденсаторы
24 Емкость проводящей сферы $$C = 4\pi\varepsilon_0 R$$
25 Энергия заряженной сферы $$W = \frac{q^2}{2C} = \frac{q^2}{8\pi\varepsilon_0 R}$$
26 Емкость плоского конденсатора $$C = \frac{\varepsilon\varepsilon_0 S}{d}$$
27 Емкость сферического конденсатора $$C = 4\pi\varepsilon\varepsilon_0 \frac{R_1 R_2}{R_2 - R_1}$$
28 Емкость цилиндрического конденсатора $$C = \frac{2\pi\varepsilon\varepsilon_0 l}{\ln(R_2 / R_1)}$$
29 Параллельное соединение конденсаторов $$C_{\text{общ}} = \sum C_i = C_1 + C_2 + \dots + C_n$$
30 Последовательное соединение конденсаторов $$\frac{1}{C_{\text{общ}}} = \sum \frac{1}{C_i} = \frac{1}{C_1} + \frac{1}{C_2} + \dots + \frac{1}{C_n}$$
31 Связь напряженности и индукции электростатического поля в веществе $$\vec{D} = \varepsilon_0 \vec{E} + \vec{P} = \varepsilon\varepsilon_0 \vec{E}$$
32 Вектор поляризации $$\vec{P} = \frac{\sum \vec{p}_i}{V} = \chi \varepsilon_0 \vec{E}$$
БЛОК 4: Постоянный ток
33 Закон Ома для однородного участка цепи $$I = \frac{U}{R}$$
34 Закон Ома для замкнутой цепи $$I = \frac{\varepsilon}{R + r}$$
35 Сопротивление проводника $$R = \rho \frac{l}{S} = \frac{1}{\gamma} \frac{l}{S}$$
36 Последовательное соединение резисторов $$R_{\text{общ}} = \sum R_i = R_1 + R_2 + \dots + R_n$$
37 Параллельное соединение резисторов $$\frac{1}{R_{\text{общ}}} = \sum \frac{1}{R_i} = \frac{1}{R_1} + \frac{1}{R_2} + \dots + \frac{1}{R_n}$$
38 Закон Джоуля-Ленца $$Q = I^2 R t = U I t = \frac{U^2}{R} t$$
39 Мощность тока $$P = \frac{A}{t} = U I = I^2 R = \frac{U^2}{R}$$
40 Закон Ома в дифференциальной форме $$\vec{j} = \sigma \vec{E} = \gamma \vec{E}$$
41 Первое правило Кирхгофа $$\sum_k I_k = 0$$
42 Второе правило Кирхгофа $$\sum_k I_k R_k = \sum_k \varepsilon_k$$
БЛОК 5: Магнетизм. Источники поля
43 Закон Био-Савара-Лапласа $$d\vec{B} = \frac{\mu_0}{4\pi} \frac{I [d\vec{l} \times \vec{r}]}{r^3}$$
44 Индукция магнитного поля бесконечного прямого провода $$B = \frac{\mu_0 I}{2\pi r}$$
45 Индукция магнитного поля провода конечной длины $$B = \frac{\mu_0 I}{4\pi r} (\cos\alpha_1 - \cos\alpha_2)$$
46 Поле в центре кругового витка $$B = \frac{\mu_0 I}{2R}$$
47 Поле соленоида (бесконечного или когда длина >> диаметра) $$B = \mu_0 n I$$
48 Поле на оси соленоида длины l и радиуса R $$B = \frac{\mu_0 n I}{2} (\cos\beta_1 - \cos\beta_2)$$
49 Поле тороида $$B = \frac{\mu_0 N I}{2\pi r}$$
50 Теорема о циркуляции вектора магнитной индукции $$\oint_L \vec{B} \cdot d\vec{l} = \mu_0 \sum I_k$$
БЛОК 6: Магнетизм. Действие поля
51 Поток магнитной индукции $$\Phi = \int_S \vec{B} \cdot d\vec{S} = B S \cos\alpha$$
52 Сила Ампера $$d\vec{F} = I [d\vec{l} \times \vec{B}]$$
53 Сила взаимодействия параллельных токов $$F = \frac{\mu_0 I_1 I_2}{2\pi d} l$$
54 Сила Лоренца $$\vec{F} = q (\vec{E} + [\vec{v} \times \vec{B}])$$
55 Момент сил на рамке $$\vec{M} = \vec{p}_m \times \vec{B} = I S [\vec{n} \times \vec{B}] \quad \Rightarrow \quad M = p_m B \sin\alpha$$
56 Намагниченность $$\vec{J} = \frac{\sum \vec{p}_m}{V} = \chi \vec{H}$$
57 Связь напряженности и индукции магнитного поля в веществе $$\vec{B} = \mu_0 (\vec{H} + \vec{J}) = \mu\mu_0 \vec{H}$$
БЛОК 7: Электромагнитная индукция и Колебания
58 Закон Фарадея (электромагнитной индукции) $$\varepsilon_i = -\frac{d\Phi}{dt}$$
59 Индуктивность соленоида $$L = \mu\mu_0 n^2 V = \mu\mu_0 \frac{N^2}{l} S$$
60 Энергия катушки индуктивности $$W = \frac{L I^2}{2}$$
61 Энергия магнитного поля $$\text{Полная: } W = \frac{L I^2}{2} \quad \text{Плотность: } w = \frac{B^2}{2\mu\mu_0} = \frac{\mu\mu_0 H^2}{2}$$
62 Ток при размыкании цепи $$I = I_0 e^{-\frac{R}{L} t}$$
63 Ток при замыкании цепи $$I = I_0 \left(1 - e^{-\frac{R}{L} t}\right)$$
64 Циклическая частота колебательного контура $$\omega = \frac{1}{\sqrt{LC}}$$
65 Скорость электромагнитной волны $$v = \frac{1}{\sqrt{\varepsilon\varepsilon_0 \mu\mu_0}} = \frac{c}{\sqrt{\varepsilon\mu}}$$
