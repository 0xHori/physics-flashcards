# 📚 Карточки для запоминания формул по физике

Интерактивное веб-приложение для изучения и запоминания физических формул с использованием техники интервального повторения (spaced repetition).

## 🌟 Особенности

- **Два режима обучения**:
  - 📝 Текст → Формула: показывается название формулы, нужно выбрать правильное изображение
  - 🖼️ Формула → Текст: показывается изображение формулы, нужно выбрать правильное название
  
- **4 варианта ответа** в каждом вопросе
- **Визуальная обратная связь** с подсветкой правильных/неправильных ответов
- **Статистика прогресса** в реальном времени
- **Адаптивный дизайн** для всех устройств
- **Простая настройка** и добавление новых формул

## 🚀 Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/0xHori/physics-flashcards.git
cd physics-flashcards
```

### 2. Структура проекта

```
physics-flashcards/
├── index.html          # Главная страница
├── styles.css          # Стили приложения
├── script.js           # Логика приложения
├── data.json          # Данные формул (JSON)
├── img/               # Папка с изображениями формул
│   ├── form1.png
│   ├── form2.png
│   └── ...
└── README.md          # Документация
```

### 3. Запуск приложения

**Вариант 1:** Открыть `index.html` прямо в браузере

**Вариант 2:** Использовать локальный сервер (рекомендуется):

```bash
# Если установлен Python
python -m http.server 8000

# Или с Python 3
python3 -m http.server 8000
```

Затем перейдите по адресу: `http://localhost:8000`

## 📊 Добавление новых формул

### 1. Подготовьте изображение формулы

1. Создайте скриншот формулы или нарисуйте её
2. Сохраните в папку `img/` с понятным именем, например: `newton_law.png`

### 2. Добавьте запись в `data.json`

Откройте файл `data.json` и добавьте новую запись в объект `formulas`:

```json
{
  "formulas": {
    "img/form1.png": "Количество вещества",
    "img/form2.png": "Молярная масса",
    "img/newton_law.png": "Второй закон Ньютона",
    "img/new_formula.png": "Название новой формулы"
  }
}
```

**Формат:** `"путь/к/изображению.png": "Название формулы"`

### 3. Готово!

Новая формула автоматически появится в приложении при следующей загрузке.

## 🎮 Использование приложения

### Основные элементы интерфейса

1. **Верхняя панель:**
   - Кнопка переключения режима (📝 ↔ 🖼️)
   - Кнопка сброса прогресса
   - Счетчик правильных ответов

2. **Область вопроса:**
   - Показывает либо название формулы, либо её изображение (в зависимости от режима)

3. **Варианты ответов:**
   - 4 варианта, один из которых правильный
   - Щелкните, чтобы выбрать ответ

4. **Кнопка "Следующая карточка":**
   - Становится активной после выбора ответа
   - Переход к следующей формуле

### Режимы работы

#### 📝 Режим "Название → Формула"
- **Вопрос:** Название физического процесса/закона
- **Ответы:** 4 изображения формул
- **Цель:** Научиться визуально распознавать формулу по её названию

#### 🖼️ Режим "Формула → Название"
- **Вопрос:** Изображение формулы
- **Ответы:** 4 названия формул
- **Цель:** Научиться называть формулу по её виду
